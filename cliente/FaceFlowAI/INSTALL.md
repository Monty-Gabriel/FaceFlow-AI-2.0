# FaceFlowAI — Ejecutable

## Instalación
1. Descarga `FaceFlowAI.rar` desde [**Releases**](https://github.com/Monty-Gabriel/FaceFlow-AI-2.0/releases/latest)
2. Extrae el `.rar` en esta carpeta
3. Haz doble clic en `FaceFlowAI.exe`

> El archivo `_internal/` (dependencias) viene dentro del `.rar` — es necesario para que el exe funcione.
